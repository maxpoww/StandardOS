# Keyboard shortcuts

Every shortcut of StandardOS, in one place. <kbd>Super</kbd> is the key with the logo on it (Windows or command key). You can add your own: see [Configuration](#expert-configuration--your-own-desktop-configuration) in the Expert part.

## The essentials

| Keys | What it does |
|---|---|
| <kbd>Super</kbd> (tap alone) | Open or close the box: apps, search, files, settings |
| <kbd>Super</kbd>+<kbd>J</kbd> | Fast launch: a quick search for apps only |
| <kbd>Super</kbd>+<kbd>H</kbd> | Quick controls: find a setting by its name |
| <kbd>Super</kbd>+<kbd>Ctrl</kbd> (tap) | Controls |
| <kbd>Super</kbd>+<kbd>L</kbd> | Lock the screen |
| <kbd>Super</kbd>+<kbd>Esc</kbd> | Sleep |
| <kbd>Super</kbd>+<kbd>E</kbd> | Terminal |
| <kbd>Super</kbd>+<kbd>F</kbd> | A file manager in the terminal (yazi); Standard Files opens from the box |

## Windows

| Keys | What it does |
|---|---|
| <kbd>Super</kbd>+<kbd>Q</kbd> or <kbd>Alt</kbd>+<kbd>F4</kbd> | Close the window |
| <kbd>Super</kbd>+<kbd>Tab</kbd> or <kbd>Alt</kbd>+<kbd>Tab</kbd> | Next window (most used first) |
| <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> or <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | The other way |
| <kbd>Super</kbd>+<kbd>Z</kbd> | Float or tile the window |
| <kbd>Super</kbd>+<kbd>P</kbd> | Keep the window its own size, in place (pseudo-tile) |
| <kbd>Super</kbd>+<kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | Move the focus up, left, down, right |
| <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | Move the window up, left, down, right |
| <kbd>Super</kbd>+arrow keys | Resize the window |
| <kbd>Super</kbd>+drag | Move the window |

## Desks, screens and the overview

| Keys | What it does |
|---|---|
| <kbd>Super</kbd>+<kbd>1</kbd>…<kbd>9</kbd>, <kbd>Super</kbd>+<kbd>0</kbd> | Bring desk 1…9 (or 10) to this screen |
| <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>1</kbd>…<kbd>9</kbd>, <kbd>0</kbd> | Send the window to that desk |
| <kbd>Super</kbd>+<kbd>`</kbd> | Go to the next screen |
| <kbd>Super</kbd>+<kbd>R</kbd> | The overview: every desk and its windows (again: the next desk with windows) |
| In the overview: <kbd>1</kbd>…<kbd>9</kbd> · <kbd>Q</kbd> · <kbd>Esc</kbd> | Go to that desk · close the window under the pointer · close the overview |
| <kbd>Super</kbd>+<kbd>Return</kbd> | Stage: the window alone, everything else below |
| <kbd>Super</kbd>+<kbd>Shift</kbd>+<kbd>Esc</kbd> | Leave the stage, whatever happens |

## Touchpad gestures

| Gesture | What it does |
|---|---|
| Three or four fingers, left or right | Previous or next desk |
| Three fingers up | Spread the windows of this desk; again: the overview |
| Three fingers down | Back from the spread or the overview |
| Four fingers up / down | Stage on / off |

## The card, voice and emoji

| Keys | What it does |
|---|---|
| <kbd>Super</kbd>+<kbd>.</kbd> | The card, on the clipboard |
| <kbd>Super</kbd>+<kbd>,</kbd> | The card, on emoji |
| <kbd>Super</kbd>+<kbd>/</kbd> | The card, on your sessions |
| <kbd>Super</kbd>+<kbd>Space</kbd> (hold) | Dictate: talk, let go, and the words are typed |
| <kbd>Super</kbd>+<kbd>Space</kbd> (tap) | The card, on voice to text |
| <kbd>Esc</kbd> while the words are being written | Cancel the dictation |

## Screenshots

| Keys | What it does |
|---|---|
| <kbd>Print</kbd> | The screen, at once (click the preview to cut a part) |
| <kbd>Print</kbd> held 1.5 s | Record the screen; <kbd>Print</kbd> again stops |
| <kbd>Shift</kbd>+<kbd>Print</kbd> | The whole screen, with a notification |
| <kbd>Alt</kbd>+<kbd>Print</kbd> | The window, with a notification |
| <kbd>Ctrl</kbd>+<kbd>Print</kbd> | Start or stop recording |

## The keyboard's own keys

These work even on the lock screen, except the short press of the power key.

| Key | What it does |
|---|---|
| Power key, short press | The power pills: Hibernate · Sleep · Restart |
| Power key, held 5 seconds | Turn off |
| Volume, mute, microphone mute | Sound |
| Brightness | The screen's brightness |
| Keyboard light | The keys' light, where there is one |
| Play/pause, next, previous | Music and video |

## In the box

| Keys | What it does |
|---|---|
| Type | Search |
| <kbd>Enter</kbd> | Open (always a new window) |
| <kbd>Shift</kbd> on an app | Its actions, recent files and Uninstall |
| <kbd>Space</kbd> on a file | Quick Look |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> on a file | Show it in Standard Files |
| <kbd>/</kbd> in an empty search | Deep file search |
| <kbd>.</kbd><kbd>/</kbd> | The box becomes a terminal |
| <kbd>Ctrl</kbd>+<kbd>Delete</kbd> on a file | Move it to the Bin |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>−</kbd> / <kbd>0</kbd> | Bigger, smaller, as it was |

| Keys | What it does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>X</kbd> / <kbd>V</kbd> | Copy, cut, paste |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> (or just type) | Search |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | Type a path |
| <kbd>Ctrl</kbd>+<kbd>H</kbd> | Hidden files |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> · <kbd>Ctrl</kbd>+<kbd>W</kbd> · <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | New tab · close tab · next tab |
| <kbd>Space</kbd> · <kbd>Enter</kbd> · <kbd>F2</kbd> · <kbd>Delete</kbd> | Quick Look · open · rename · to the Bin |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | New folder |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> / <kbd>Ctrl</kbd>+<kbd>2</kbd> | Grid / list |
| <kbd>Backspace</kbd> or <kbd>Alt</kbd>+<kbd>←</kbd> · <kbd>Alt</kbd>+<kbd>→</kbd> · <kbd>Alt</kbd>+<kbd>↑</kbd> | Back · forward · up |
| <kbd>Shift</kbd>+<kbd>F10</kbd> or the Menu key | The menu |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Keyboard mode (<kbd>?</kbd> lists its keys) |

## Quick Look

| Keys | What it does |
|---|---|
| <kbd>Space</kbd> or <kbd>Esc</kbd> | Close |
| Arrow keys | The next file |
| <kbd>Enter</kbd> | Open it in its app |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | A PDF's pages, or scroll text |
| <kbd>Ctrl</kbd>+wheel, <kbd>+</kbd> / <kbd>−</kbd>, double-click, <kbd>0</kbd> | Zoom a photo |
| <kbd>P</kbd> | Play or pause |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> · <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> · <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Save · save a copy · undo (while editing) |

## Menus (every right-click)

| Keys | What it does |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> · <kbd>Home</kbd> <kbd>End</kbd> | Move between rows |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Choose |
| <kbd>→</kbd> · <kbd>←</kbd> | Into a page (›) · back |
| A letter | The next row that starts with it |
| <kbd>Esc</kbd> | Close the menu |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>−</kbd> / <kbd>0</kbd> | Every menu bigger, smaller, as it was |

## The browser (Seam)

| Keys | What it does |
|---|---|
| <kbd>Alt</kbd> (tap alone) | All your tabs as a grid |
| In the grid: <kbd>1</kbd>…<kbd>9</kbd> · <kbd>T</kbd> · <kbd>Q</kbd> · <kbd>Esc</kbd> | Go to that tab · new tab · close the tab · close the grid |

Every other browser shortcut is Firefox's.
